Le fond vert, les masques et les outils de découpage sont des fonctionnalités puissantes pour créer des vidéos impactantes, même sans logiciel complexe. Avec CapCut Desktop, il est possible de les utiliser facilement pour obtenir des effets professionnels. Voici un guide complet pour apprendre à maîtriser ces outils.

### **Supprimer un fond vert avec le Chroma Key dans CapCut**

#### **Étape 1 : Importer votre séquence avec fond vert**

Ajoutez votre clip à fond vert dans la timeline de CapCut. Assurez-vous que le fond est bien uni et éclairé.

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-04-24_a_16.32.14-1-1024x498.webp)

#### **Étape 2 : Sélectionner le clip et activer « Clé Chroma »**

Dans le panneau latéral droit, cliquez sur l’option **Clé Chroma**. Utilisez l’outil pipette pour sélectionner la couleur verte à supprimer.

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-05-09_a_10.23.48-1024x636.webp)

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-05-09_a_10.22.59-1024x521.webp)

#### **Étape 3 : Ajuster les paramètres de suppression**

Ajustez **l’ombre**, l’**intensité**, et le **bord** pour obtenir une suppression nette sans halo.

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-04-24_a_16.35.37-1-1024x501.webp)

#### **Étape 4 : Ajouter un nouveau fond**

Ajoutez une image ou une vidéo en arrière-plan sur une piste en dessous pour remplacer le fond vert.

**Astuce pro :** un bon éclairage et un fond uniforme facilitent une suppression de qualité.

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-04-24_a_16.39.46-1024x513.webp)

### **Utiliser les masques dans CapCut Desktop**

#### **Étape 1 : Ajouter un calque**

Ajoutez un deuxième clip ou une image au-dessus de la vidéo principale sur la timeline.

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-05-09_a_10.26.21-1024x532.webp)

#### **Étape 2 : Sélectionner le calque et cliquer sur « Masque »**

Dans le menu des effets, choisissez **Masque**, puis la forme souhaitée (cercle, rectangle, triangle, etc).

#### **Étape 3 : Ajuster et animer le masque**

Vous pouvez ajuster la taille, la position et la direction du masque. Utilisez les **keyframes** pour l’animer (ex : effet de révélation).

**Exemple d’utilisation :** faire apparaître un visage ou un logo dans un cercle animé.

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-05-09_a_10.26.47-1024x543.webp)

### **Utiliser le découpage automatique (Auto Cutout)**

#### **Étape 1 : Importer une vidéo avec sujet sur fond neutre**

CapCut peut automatiquement isoler un sujet humain sans fond vert.

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-04-24_a_16.46.39-1024x538.webp)

#### **Étape 2 : Activer « Suppression d’arrière-plan »**

Dans le menu latéral, cliquez sur l’option **Auto Cutout** ou « Background Remover ». Le sujet est automatiquement isolé.

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-05-09_a_10.53.28-1-1024x638.webp)

#### **Étape 3 : Ajouter un fond dynamique**

Ajoutez une scène, une animation ou un décor stylisé derrière le sujet pour un effet immersif.

**Limites :** fonctionne mieux avec peu de mouvement et un fond contrasté.

![](/images/blog/comment-utiliser-les-masques-les-decoupages-ou-les-green-screen-avec-chroma-key-dans-capcut-2/Capture_decran_2025-04-24_a_16.48.51-1-1024x479.webp)

### **Idées créatives avec masques, fond vert et découpage**

-   Révélation stylée d’un produit avec masque animé
-   Vidéo « avant/après » avec effet split screen
-   Changement de décor pour une interview
-   Ajout d’animations autour du sujet isolé (ex : interface futuriste)
